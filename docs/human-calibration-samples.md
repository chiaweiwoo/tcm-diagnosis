# Human Calibration Samples (Non-Binding)

These samples are real doctor-style references shared by the project owner.
They are used to calibrate tone and practicality, not as strict expected outputs.

## Usage Rules

- Use these samples to tune concise and practical clinical wording.
- Do not enforce exact matching in tests.
- Do not treat these as universal standards for all case types.
- Keep supportive senior-peer tone: acknowledge reasonable parts first, then suggest improvements.

## Sample A (Trigger Finger / Acupuncture)

Draft:

患者女54岁，右侧拇指弹响指半年余，数次针刺疗法后，拇指尚无法弯曲，掌面掌指关节压痛，活动时酸楚。

针刺穴位：阿是穴，合谷穴。

根据网上可查询的临床研究文献，对改方案进行改良，要求疗效进步

Reference style highlights:

- Focus quickly on key local adjustment.
- Keep point-level recommendations concise.
- Prioritize practical improvement over long theory explanation.

## Sample B (PCOS / Formula)

Draft:

患者33岁，素食者

停经9月余，有PCOS。服用荷尔蒙药物2周催经，停药后月经来潮。点滴不畅，少许痛经。

开药：杏仁10g 红花10g 熟地黄10g 赤芍10g 補骨脂10g 三棱5g 莪术5g 香附10g 丹参10g 益母草10g 肉從蓉10g 巴戟天10g

服用5日，月经干净，现以调理下次月经周期为主，月经干净后以给以以下方药颗粒5日：

（复方颗粒）六味地黄5g 巴朝天1g 女贞子1g 枸杞子1g 香附1g 熟地黄1g 肉苁蓉1g

结合现有临床研究，结合以上病案，请做出判断，并给予意见和需要更改的地方

Reference style highlights:

- Keep dosage adjustment suggestions concrete.
- Include practical nutrition/check/monitoring reminders.
- Keep recommendations realistic for follow-up execution.
